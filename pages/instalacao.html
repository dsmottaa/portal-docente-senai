Como instalar e rodar

Guia para rodar (e mexer) no código em qualquer máquina

Requisitos

  • Node.js 22+ (recomendado: 24 LTS) instalado — baixe gratuitamente em nodejs.org.
  • Sem dependências: não precisa de npm install nem de instalar nenhum pacote.
  • Gerador de PDF agora é local (js/vendor/) — funciona offline. Internet só precisa uma vez para fontes do navegador.

Passo a passo para rodar

  1. Baixe a pasta do projeto (ou clone do GitHub).
  2. Descompacte e entre na pasta.
  3. Dê dois cliques no arquivo iniciar-sistema.bat.
  4. O portal abre sozinho no navegador em http://localhost:8000.
  5. Faça login: professor 123.456.789-00 / senha senai2026 — coordenação coord.senai / coordenador2026.
  6. Para encerrar, feche a janela do servidor.

Estrutura do projeto (para quem vai mexer no código)

  • server.js → servidor, API (/api/*) e banco SQLite.
  • pages/ → telas (HTML). index.html é o login.
  • js/ → lógica. data.js = dados no navegador, auth.js = proteção das páginas.
  • css/ → visual (style.css + features.css). img/ → imagens.
  • service-worker.js + manifest.json → modo PWA (oficial/offline).
  • js/vendor/ → bibliotecas embutidas (jsPDF) para funcionar sem internet.
  • portal.sqlite + backups/ → dados e cópias de segurança.
  • .vscode/launch.json → debug do Chrome já configurado.

Como os dados funcionam

  • Os dados ficam no navegador (localStorage) e são sincronizados com o SQLite do servidor.
  • Backup automático a cada 2 horas em backups/ + exportação manual em Configurações.
  • Para começar do zero numa máquina: apague portal.sqlite, portal.sqlite-wal e portal.sqlite-shm. O sistema recria tudo com dados de demonstração no primeiro acesso.
  • Cada unidade só grava nas próprias chaves (isolamento) e há trilha de auditoria de quem alterou o quê.

Assistente IA (Ollama) — opcional

  • A IA é local: o portal conversa com o Ollama da própria máquina, então cada computador precisa do Ollama instalado.
  • Forma rápida: dê dois cliques no arquivo instalar-tudo.bat — ele baixa, instala e puxa o modelo automaticamente.
  • Manual: instale em ollama.com e rode no terminal ollama pull qwen2.5:3b (uma vez só).
  • Sem o Ollama, o portal funciona normalmente — só a parte de respostas "inteligentes" fica limitada ao modo offline.

Google Classroom — opcional

  • Integração via OAuth 2.0, configurada em configuracao.html.
  • Importante: os arquivos classroom-config.json e classroom-tokens.json contêm credenciais e nunca devem ser enviados/compartilhados (já estão no .gitignore).
  • Sem credenciais, o portal mantém um feed simulado local.

Dicas de desenvolvimento

  • Rodar manualmente: node server.js na pasta do projeto.
  • Porta padrão 8000; o arquivo iniciar-sistema.bat encerra qualquer processo antigo na porta antes de subir.
  • Modelo padrão da IA: qwen2.5:3b (ajustável em server.js via MODEL).
  • Para publicar no GitHub, o .gitignore já protege o banco e as credenciais.
